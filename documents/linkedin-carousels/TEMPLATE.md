# LinkedIn Carousel Template ("Data Check" style)

Reference: Hartamas "The Launch Question" carousel (NAPIC Q3 2026, 8 slides).
Use this for every future LinkedIn post: one carousel plus one caption.

---

## 1. Visual system

| Element | Spec |
|---|---|
| Size | 1080 × 1350 (4:5 portrait), 8 slides |
| Background | Warm beige (#F3E9DC) with a faint graph-paper grid |
| Top left | Series label in caps: `THE [TOPIC] • 0N` |
| Top right | Brand logo in a yellow block (#FFE000) |
| Headline | Heavy black sans-serif (Inter Black, Satoshi or similar), 2–3 lines |
| Highlight | One key word in a pastel box with "text selection" handles (dot at each corner) |
| Accent colour | One per slide, rotating: purple #B98CE0, green #3DBE7A, blue #8CC8F5 |
| Divider | Short accent line (~100 px) under the headline |
| Body | 1–3 short lines, regular weight, dark grey |
| Takeaway box | Black block, white text, ALL CAPS, 3–5 words a line |
| Data visual | One per slide: bar chart, stat cards, or table with % chips |
| Illustration | Bottom right: photoreal cut-out (person with tablet, buildings, skyline) |
| Footer left | Source line: `[Source] ([date]) • [dataset]` |
| Footer right | Pill: `0N/08 Swipe →` |

## 2. Slide formula

Every slide answers one question and has the same 6 layers:

1. **Label**: `THE [ANGLE] • 0N`
2. **Headline**: the number or claim (highlight one word)
3. **Twist line**: the "but…" in an accent band
4. **Context**: 1–3 lines explaining the number
5. **Proof**: chart, cards or table
6. **Takeaway**: black box rule the reader should remember

## 3. 8-slide story arc

| # | Label | Job | Example (from reference) |
|---|---|---|---|
| 01 | THE [HOOK] QUESTION | Big headline stat + "But what about…?" | New launches up 70%. But what about sales? |
| 02 | THE [X] PICTURE | Show the gap between two numbers | 19,642 launched. Sales performance: 7.1% |
| 03 | THE HIDDEN [X] | Risk most people miss | Unsold stock is already built |
| 04 | THE LOCAL DIVIDE | Break the national number down | KL +14%, Penang −12% |
| 05 | THE [SEGMENT] VIEW | Price band, product type or buyer type | |
| 06 | THE [TREND] SIGNAL | Year-on-year or multi-quarter trend | |
| 07 | THE CHECKLIST | 3–5 things the audience should check | |
| 08 | THE TAKEAWAY | One-line summary + CTA (follow, comment, DM) | |

## 4. Writing rules

- Plain English. Short words. Active voice.
- One idea per slide. Max ~35 words of body text.
- Lead with a number. Then the twist.
- Takeaway boxes use the pattern `X ≠ Y` or `CHECK X, NOT JUST Y`.
- Always cite the source and date in the footer. Mark preliminary data.
